# Beta User Observations

این سند یک ساختار سبک برای ثبت مشاهدات واقعی کاربران در مرحله‌ی بتا فراهم می‌کند. هدف، ضبط رفتار کاربر، نشانه‌های مثبت، اصطکاک، فرضیه‌ها و شواهد بدون ساختن زیرساخت analytics یا اعمال تغییرات محصولی است.

## Evidence Model

- Observed User Evidence: شواهد مستقیم از رفتار، اقدام یا گفتار کاربر
- Product/UX Evidence: شواهد حاصل از تجربه‌ی فعلی محصول یا تحلیل UX
- Technical Evidence: شواهد حاصل از تست، runtime یا اعتبارسنجی فنی

برای این فاز، تمرکز اصلی روی Observed User Evidence است.

### Friction

### Impact

### Confidence

Low / Medium / High

### Potential Problem

### Decision

### Notes

Additional context.

## Observation Rules

- ثبت دقیق آنچه اتفاق افتاد
- ثبت نقل‌قول دقیق در صورت امکان
- ثبت رفتار موفق و رفتار با اصطکاک
- ثبت hesitancy، تردید و الگوهای تکرارشونده
- از تفسیر زودهنگام پرهیز شود
- از تبدیل یک مشاهدات فردی به تصمیم محصولی سریع خودداری شود
